---
title: Templates
---

You can add resource templates to your pack, which are a useful way to provide examples or pre-made signs for users to use.

Resource templates are located in the `signs/templates` folder of your pack.

## Creating a Template

### Create the Road Sign [step]
To create a template, first, create a sign in game, or open the editor
of the sign you want to save as a template.

### Export as Template [step]
Then, inside the editor, click on "Export Template".

> Here, you can check **Include Written Texts** if you want the template
to include the text that is written on the sign.
Otherwise, all text elements will have empty text.

You can also change the name and author of the template here.

Then, you have two ways to save the template:

#### Copy Template Json [step]
Click on "Copy Template Json" to copy the template json to your clipboard.

Create a json file in the `signs/templates` folder of your pack,
and paste the copied template json into it.

#### Save to Local Templates [step]
Click on "Save to Local Templates" to save the template json to your local templates folder.

Copy the saved template json from your local templates (`.minecraft/sign_templates`) folder
into your pack's `signs/templates` folder.

### Done! [step]

Your template will now show up in the "Resource Templates" tab
of the template selector!
